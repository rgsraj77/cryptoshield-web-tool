# Cryptographic Protocol Risk & Lean 4 Verification Workbench
**Author:** Raj Guru Suwalka | **Supervisor:** Dr. Edon Kelmendi (Queen Mary University of London, 2025–26)

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## How to Publish Live on Streamlit Community Cloud (Free & Public)
1. Create a new public GitHub repository (e.g., `crypto-protocol-risk-verifier`).
2. Upload all files from this folder (`app.py`, `requirements.txt`, `final_dv1.csv`, `protocol_ranking.csv`, and `.streamlit/config.toml`).
3. Visit [share.streamlit.io](https://share.streamlit.io/) and sign in with GitHub.
4. Click **New app**, select your repository, set **Main file path** to `app.py`, and click **Deploy!**
5. Your app will be live in ~60 seconds with a shareable public URL.
